# Code of Conduct

## AI-Based Purchasing Tendency

We are committed to creating a welcoming, respectful, inclusive, and constructive environment for everyone participating in this project.

This Code of Conduct is based on the principles of the widely used **Contributor Covenant**.

---

## 🌟 Our Standards

Examples of behavior that contribute to a positive environment include:

* Being respectful and considerate.
* Communicating constructively.
* Welcoming different perspectives.
* Providing helpful technical feedback.
* Accepting constructive criticism.
* Focusing on the technical problem rather than individuals.
* Respecting different levels of experience.
* Supporting collaborative learning.

---

## 🚫 Unacceptable Behavior

The following behaviors are not acceptable:

* Harassment or discrimination.
* Personal attacks.
* Insulting or derogatory comments.
* Trolling or intentionally disruptive behavior.
* Publishing private information without permission.
* Threats or intimidation.
* Unwanted sexualized behavior.
* Deliberate disruption of project discussions.
* Any behavior that creates an unsafe or hostile environment.

---

## 💬 Technical Discussions

Technical disagreements are normal in software and AI development.

When disagreements occur:

1. Focus on evidence and technical reasoning.
2. Explain the advantages and disadvantages of proposed approaches.
3. Respect alternative solutions.
4. Avoid personal criticism.
5. Work toward a constructive resolution.

---

## 🧑‍💻 Contribution Expectations

Contributors should:

* Follow the contribution guidelines.
* Keep pull requests focused.
* Explain significant changes clearly.
* Respect project maintainers and other contributors.
* Avoid committing sensitive information.
* Follow the project's security requirements.

---

## 🛡️ Enforcement

Project maintainers may take appropriate action when behavior violates this Code of Conduct.

Possible actions include:

* Requesting changes to behavior.
* Removing inappropriate content.
* Closing discussions.
* Rejecting contributions.
* Restricting participation when necessary.
